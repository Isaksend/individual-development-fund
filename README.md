# Individual Development Fund — сайт

Статичный одностраничный сайт (HTML + CSS + JS, без сборки). Открыть `index.html` в браузере.

## Структура
- `index.html` — русская версия
- `en.html` — английская версия
- `kz.html` — казахская версия (шрифт Montserrat: в Jost нет казахских букв). Переключатель RU / EN / KZ — в шапке.
- `css/styles.css` — стили (цвета и шрифт в `:root`)
- `js/main.js` — меню, фильтр событий, счётчики, анимации, форма подписки

## Разделы
Объявление · Шапка · Hero · Миссия · Цифры · Направления (6) · Форматы (10) · Открытый конкурс · События (фильтр по направлениям) · Новости · Исследования · Присоединяйтесь (участникам / бизнесу / экспертам) · Подписка · Подвал

## Что заменить перед запуском
- Фото: блоки с классом `ph ph--*`. Сейчас это стоковые фото с Unsplash (бесплатная лицензия, ссылки на images.unsplash.com) — замените на собственные фото фонда, поменяв `background-image: url(...)` в `styles.css` (раздел «Фотографии»).
- Цифры в блоке «Цифры» — целевые, замените на реальные.
- События, новости, публикации, контакты (`info@example.org`), соцсети, домен в JSON-LD.
- Форма подписки — подключить к сервису рассылок (сейчас демо).
